## 🛠️ TECH STACK

> "Quick overview of the tech stack behind all this:
>
> **Frontend:** React 18 with Vite for lightning-fast builds, Tailwind CSS with Shadcn UI components for that polished look.
>
> **Backend:** Node.js with Express.js handling the API, MongoDB Atlas for cloud database, Mongoose for clean data modeling.
>
> **Authentication:** JWT tokens for stateless sessions, plus Google OAuth 2.0 for one-click sign-in.
>
> **Third-Party Integrations:**
> - **OpenAI GPT-Image-1** for AI room visualization
> - **Cloudinary** for image storage and optimization
> - **Nodemailer** with Gmail SMTP for transactional emails
>
> **Deployment:** Everything containerized with Docker Compose, running on AWS EC2 with Nginx reverse proxy and Certbot SSL certificates."

---

## 🚀 DEPLOYMENT

> "For deployment, I've Dockerized the entire application:
>
> The frontend and backend run in separate containers, orchestrated with Docker Compose. One command - `docker-compose up --build -d` - and everything deploys.
>
> It's running on an **AWS EC2 instance** with Ubuntu. Nginx handles reverse proxying and SSL termination. I configured Certbot for automatic HTTPS certificate renewal.
>
> The domain **chandanhousepainting.com** is live right now, serving real customers in Ontario!"
